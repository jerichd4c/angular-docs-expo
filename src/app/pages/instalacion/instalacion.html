1. Instalación y estructura del proyecto

Angular es un framework de Google para construir aplicaciones web con TypeScript. Todo se maneja desde el Angular CLI, una herramienta de terminal que crea, ejecuta y compila proyectos.

Requisitos previos

Angular necesita Node.js, que incluye npm (el gestor de paquetes). Se descarga desde nodejs.org; se recomienda la versión LTS.

Instalar el Angular CLI

Se instala una sola vez de forma global, para usar el comando ng desde cualquier carpeta.

Crear y ejecutar un proyecto

ng new crea el proyecto con todo configurado. Durante la creación, el CLI pregunta qué asistentes de IA configurar (por ejemplo Claude Code). La opción --ssr activa el renderizado en el servidor desde el inicio. Luego ng serve levanta la app en http://localhost:4200 y la recarga automáticamente con cada cambio.

Estructura del proyecto

Esta es la estructura real de esta documentación. Casi todo el trabajo se hace dentro de src/app.

Archivos clave

ArchivoFunción
main.tsArranca la aplicación cargando el componente raíz.
index.htmlLa única página HTML; Angular dibuja todo dentro de <app-root>.
app.tsComponente raíz: el primero que se muestra y contiene a los demás.
app.config.tsRegistra servicios globales: router, cliente HTTP, hidratación.
angular.jsonLe dice al CLI cómo compilar, servir y probar el proyecto.
package.jsonLista las librerías que usa el proyecto y sus versiones.

Comandos más usados

Puntos clave

  • Angular requiere Node.js y se maneja con el CLI (ng).
  • ng new crea el proyecto y ng serve lo ejecuta.
  • El código de la aplicación vive en src/app.
  • Es una SPA: hay un solo index.html y Angular cambia su contenido.

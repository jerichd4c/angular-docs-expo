2. Componentes y sintaxis base

En Angular la interfaz se construye con componentes: piezas reutilizables que combinan lógica (TypeScript), estructura (HTML) y estilo (CSS). Una aplicación es un árbol de componentes, empezando por el componente raíz App.

Anatomía de un componente

Un componente es una clase de TypeScript con el decorador @Component, que le indica a Angular cómo usarla y mostrarla.

PropiedadFunción
selectorNombre de la etiqueta HTML con la que se usa el componente.
importsComponentes y directivas que se pueden usar dentro de su plantilla.
templateUrl / templateEl HTML, en un archivo aparte o escrito directamente en el .ts.
styleUrl / stylesEl CSS, que por defecto solo afecta a este componente (encapsulación).

Sintaxis de plantillas: bindings

Los bindings conectan los datos de la clase con el HTML:

  • Interpolación {{ '{' }}{{ '{' }} {{ '}' }}{{ '}' }}: muestra un valor como texto.
  • Property binding [propiedad]: asigna un valor a una propiedad de un elemento.
  • Event binding (evento): ejecuta un método cuando ocurre un evento.

Control de flujo

Angular tiene bloques propios para mostrar contenido según condiciones o repetirlo por cada elemento de una lista: @if, @for y @switch. En @for, track es obligatorio: le dice a Angular cómo identificar cada elemento para actualizar solo los que cambian.

Puntos clave

  • Un componente = clase TypeScript + decorador @Component + plantilla + estilos.
  • {{ '{' }}{{ '{' }} {{ '}' }}{{ '}' }} muestra datos, [ ] asigna propiedades y ( ) escucha eventos.
  • @if, @for y @switch controlan qué se muestra.
  • Los estilos de un componente no afectan al resto de la aplicación.
